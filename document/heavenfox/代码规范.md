<h1 align="center">HeavenFox 代码规范</h1>

    1.1, 变量及函数名称一律小写, 各单词之间使用"_"分隔. 如:
        unsigned char number_of_student;
        static unsigned int calculate_students(void)
        禁止使用全大写和大小写混合(如匈牙利命名法)

    1.2, 宏(常量)、枚举变量建议全大写. 如:
        #define UART_OFFSET                     (0x100)
        enum __ERT_STATUS { NR_STATUS_ON, NR_STATUS_OFF };

        宏名默认不需要特殊前缀, 枚举变量需使用"NR_"前缀, 用于区分宏和枚举

    1.3, 带特殊意义的(类似关键字), 或用法如函数的宏, 可以使用小写, 但需要以"mr_"前缀区分, 避免与真正的函数混淆. 如:
        #define mr_nullptr                      ((void *)0)
        #define mr_offsetof(type, member)       __compiler_offsetof(type, member)

        也可以使用全大写

    1.4, 没有"返回值"功能的类函数宏, 不能单纯使用"{}", 需要以"do { ... } while (0)"包裹. 如:
        #define mr_writel(data, addr)           do { *((volatile kuint32_t *)(addr)) = (kuint32_t)(data); } while (0)

        若没有do { ... } while (0), 则以下代码语法错误(else将因上一个"}"后带";"而无法匹配"if"):
        if (true)
            mr_writel(0x01, base);
        else
            mr_writel(0x02, base);

    1.5, if, for, while, switch后的左大括号另起一行, 目前电脑尺寸都相对较大, 不需要与关键字挤在同一行; 右大括号亦然. 如:
        if (true) 
        {
            i++;
            j++;
        }

        while ((i++) < 10) 
        {
            ...
        }

        for (i = 0; i < 10; i++) 
        {
            ...
        }

        switch (i) 
        {
            case 1:
                ...
                break;
            ...
        }

        若if后面还有else if, else, 也应另起一行, 保证代码清晰直观 
        ("lib/"和"example/"文件夹下的代码不做要求, 前者是第三方库, 无法对其设限; 后者是应用例程, 非HeavenFox的必要部分). 
        如:
        if (i == 1) 
        {
            ...
        } 
        else if (i == 2) 
        {
            ...
        } 
        else if (i == 3) 
        {
            ...
        } 
        else 
        {

        }

        if (j == 1) 
        {

        } 
        else 
        {

        }

        如作用域内仅一条语句, 不需要使用大括号(函数除外). 如:
        if (i > 10)
            printf("xxxxx\r\n");
        else
            continue;

        函数作用域的大括号需另起一行. 如:
        static void func(void)
        {
            char ch = '0';
            ...
            return;
        }

        结构体, 枚举, 共用体类型定义时, 左大括号也需另起一行. 如:
        struct student 
        {
            int number;
            char name[32];
        };

        enum student_class 
        {
            NR_STUDENT_A = 0,
            NR_STUDENT_B
        };

    1.6, 除Makefile强制以Tab缩进外, 汇编与C代码均需以4个空格缩进(1Tab = 4空格); 作用域内的代码需基于控制块缩进. 以下风格禁止:
        if (i == 1) {
        j++;
        }

        static void func(void)
        {
        return;
        }

        static void func(void)
        {
                return;
        }

        switch以下的case均需基于switch语句缩进4个空格, 不能与switch同列. 以下风格禁止:
        1) 无缩进
        switch (i) 
        {
        case 1:
            break;
        }

        2) 缩进过多
        switch (i) 
        {
                case 1:
                    break;
        }

    1.7, 为便于区分结构体、共用体与普通变量, 结构体实例需使用"sgtc"(结构体全局类型容器)作为前缀, 而指针需使用"sptr"(结构体指针)作为前缀. 如:
        struct student sgtc_student_a;
        struct student *sptr_student = &sgtc_student_a;

        共用体相应使用"ugtc"和"uptr"
        函数类型则使用"fn", 或"fn_t"后缀, 如: typedef int (*abc_fn)(int a); 也可以不使用fn, 无强制

    1.8, 不论是单行还是多行注释, 一律使用"/*!<  */", 不能用双斜线"//".
        函数内部的注释严禁与代码在同一行, 需在代码上一行注释;
        宏和枚举、全局变量的注释可以在其同一行的后方注释. 在同一行注释时, 需与代码保持距离, 且保证列对齐.
        如:
        #define mr_nullptr                      ((void *)0)     /*!< 空指针 */
        #define mr_true                         (1)             /*!< true */

        static int g_timer_count = 0;                           /*!< 全局时间计数器 */

        enum student_class 
        {
            NR_STUDENT_A = 0,                                   /*!< 学生A */
            NR_STUDENT_B                                        /*!< 学生B */
        };

        static void func(void)
        {
            /*!< 变量定义 */
            struct student *sptr_stu;

            /*!< 设置学生A的信息 */
            sptr_stu = &sgtc_student_a;
            sptr_stu->number = NR_STUDENT_A;
            sprintf(sptr_stu->name, "学生A");
        }

        函数整体功能的说明需标注在函数上方, 并以特定的注释标记方式表示. 如:
        /*!
         * @brief   函数说明
         * @param   argc: 参数数量
         * @param   argv: 参数内容
         * @retval  错误码
         * @note    注解
         */
        int main(int argc, char **argv)
        {
            return 0;
        }

    1.9, 类型关键字需使用"common/basic_types.h"中的类型, 不直接使用int, char. 如:
        kuint32_t number = 0;                                   /*!< 定义一个32位的变量 */
        kchar_t ch;                                             /*!< 定义一个字符变量 */
        kbool_t status = false;                                 /*!< 定义一个布尔变量 */

    2.0, 结构体、共用体尽量不使用typedef类型, 可直接使用"struct xxx". 如:
        struct student sgtc_student_a;
        union teacher sgtc_teacher_a;
